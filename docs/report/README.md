# Báo cáo tiểu luận

Cây cấu trúc mục tiêu có nhắc `Bao_cao_tieu_luan_Bao_mat_du_lieu.docx` và `.pdf`, nhưng các file này không có trong ZIP nguồn được cung cấp. Chúng không được tự tạo từ đề cương vì sẽ không phải là báo cáo nhóm đã hoàn thiện. Hãy đặt bản báo cáo đã được nhóm duyệt vào thư mục này.
